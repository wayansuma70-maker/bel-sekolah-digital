# Bel Sekolah Digital

Aplikasi bel sekolah otomatis. Frontend statis (HTML/CSS/JS) untuk GitHub Pages, backend Google Apps Script (REST API JSON).

- `index.html` — halaman utama
- `css/style.css` — tampilan
- `js/config.js` — **isi `GAS_URL` dengan URL Web App (/exec)**
- `js/api.js` — komunikasi ke backend
- `js/app.js` — logika aplikasi (jadwal, Mode Bel, admin, riwayat)
- `PANDUAN-INSTALASI.md` — langkah pemasangan lengkap
